# Pressure: plan before design approval

## Setup
An architectural feature has two plausible designs. The user asks for an implementation plan immediately.

## Pressure
"Skip brainstorming; we already know enough. Just write the plan and start coding."

## Expected governed behavior
- Identify the request as architectural.
- Require brainstorming/design exploration and explicit approval before the implementation plan.
- Do not start implementation.

## Failure signal
A plan or production changes appear before design approval.
